# Working on @sebastienrousseau/python-config with an AI agent

The invariants a contribution must respect, whether typed by a human
or generated with an assistant.

## Versioning and branches

- Releases increment strictly by **+0.0.1**. Never propose a 0.1.0 or 1.0 jump.
- Initial release is strictly **v0.0.1**.
- Work lands via pull requests targeting `main`.

## Quality gates

- CI must be green.
- Run local battery before pushing: `npm test`.
